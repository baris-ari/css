## Course Description 

This training event introduces core concepts, methods, and research practices in Computational Social Science (CSS) with a particular focus on complex systems, computational simulations, and agent-based modelling. 

The aim of the course is to provide doctoral researchers with a conceptual and methodological foundation for understanding when and how computational approaches can be used to address social science research questions.

## Learning Objectives

By the end of the course, participants will be able to:

* Understand the role of computational methods within the broader scientific research
* Understand key ideas and paradigms in Computational Social Science
* Become familiar with the basic principles of complexity and complex systems thinking
* Understand how micro-level behaviour and interactions between individual agents can generate emergent macro-level outcomes
* Understand the principles of agent-based modelling
* Become familiar with a range of computational methods and practical research tools used in Computational Social Science
* Make informed methodological decisions about integrating computational approaches into their own research projects

## Clarification about Coding and Prerequisites
Coding plays an important role in computational methods, but this training event is not about learning a programming language. It helps if you have a working programming environment on your computer, such as Python or R, but this is not strictly required.

**If you do not have a programming environment set up on your computer, you can use Google Colab, a free browser-based platform that lets you run Python without installing anything locally. All you need is a Google account. It can be slow, but it will do the job.**

You are free to use any programming language you prefer. I recommend using Python, R, or NetLogo (for agent-based modelling). A basic familiarity with coding is highly beneficial but not required. You can also rely on pseudo-code for planning, and use AI assistants to help you work through formalisation and implementation. We will do this in class.

This training event does not aim to teach coding syntax or to systematically improve programming proficiency. Instead, coding is treated as a practical tool for achieving substantive analytical goals: developing models and running simulations.
