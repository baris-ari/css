# Meta Schelling
- We are going to vary the threshold from 0.2 to 0.6 by 0.025.
  - Should give us 17 thresholds
- We run 200 simulations for each threshold
- For each you calculate level of similarity (percent similar).
- Average it for the threshold. Take its mean.
- We will have 17 means (% similar) for each threshold.
- Plot it: x-axis thresholds, y-axis percent-similar
